# DSH 方案规则梳理与转换

## 定位与范围

本 Skill 是旧 solution-definition-studio 面向新 DSH 插件的适配版，目的是减少业务梳理和开发工作，不是插件运行依赖或唯一编制入口。也接受同事直接维护或由其他工具生成的章节规则，统一校验产物，不强制旧平台输出格式。

本目录是新插件项目内的维护源。保留旧项目、原 authoring Skill、全局部署和旧编译器不动。本文件是行为规范，不表示转换器、资源下载或规则替换功能已实现。

按请求只做必要范围：梳理只交付确认稿；转换交付目标插件资源；章节修订只更新本章及受影响定义，不强制重建整个平台。仅作形式示例的飞书链接不读取，真实读取只限授权来源和必要范围。

## 梳理与产物

先从已有材料确认章节目标、输入、输出、依赖、知识和确认边界；不确定的业务语义列为问题，不用模型推断冒充业务批准。数据工具标准称谓为 CCPG CLI，实际命令 `ccpg-cli`；Data CLI 仅是功能描述，不使用 CCP/GLI 等口语简称或猜测的命令名。每次核实当前版本与公开能力，不开启隐藏/full 模式。能力分析和知识原文核验发生在章节 Skill 生成之前，具体步骤见 [数据与知识准备](references/data-and-knowledge.md)。

目标资源包括：

1. 方案级 `AGENTS.md`：公共业务约束、材料/工具边界、正文/附件和确认原则，使用 DSH 原生识别的文件名。
2. 各章节 `SKILL.md` 和必要 references、模板、脚本：具体处理逻辑、已核实取数策略、知识阅读路径、失败和缺料处理。
3. 最小运行定义：方案/章节稳定标识、Skill 映射、展示顺序、依赖和成熟度、输入输出、确认要求及资源版本。沿用已确定的插件契约；尚未确定格式时只提出映射，不将草案冒充可运行定义。
4. 数据能力映射与知识索引：记录取数证据、字段口径、实际本地知识路径、来源、版本及缺口，不只保留标题和 URL。

知识资源只有在其目录的 `metadata.json` 明确写入 `distributable: true` 时才可进入规则包；缺失原文、分发权未知、明确禁止分发或内容不完整都必须保留阻断。数据映射统一使用标准产品名 CCPG CLI 和实际命令 `ccpg-cli`，只有带有已验证命令、能力、字段和时间证据的映射才可标记为 verified。

全案 Skill 仅在确有调用价值时生成，不再造调度器。旧平台导入包、独立项目输入包和 Solution Amendment 仅在明确兼容任务中处理，不作为新插件的前置。辅助 Skill 留在开发侧，不要求终端用户安装或调用。

保留业务规则，移除对旧 AgentScope Worker、Temporal、Tool Gateway、旧 API 和固定初始化脚本的执行依赖；缺少替代能力应说明，不能只改名字。由原生 DSH 执行，插件只保留必要的状态和成果约定。

依赖决定就绪，目录决定展示顺序；首版就绪章节默认串行，只有必要确认才等待。正文、附件、证据、确认分离，不能因换 Runtime 丢失模板结构、知识权限或数据口径。

## 可替换与维护源

首次安装内置完整默认规则，之后章节 Skill 可独立替换，不要求重装插件界面或整个 dsh-harness-one。通过受控规则入口或指定目录更新，不直接修改 node_modules、用户全局 Skills 或已有 AGENTS.md。

同一规则只保留一个维护源：生成模式保留业务源和生成关系；直接维护模式以该版本 Skill/定义为源。重新生成前识别人工修订，禁止静默覆盖，不强制把手写修改回填旧表格。

接口兼容的措辞/指导变化可单章更新；输入输出、依赖、数据来源、工具或权限变化必须连同关联定义校验。检查章节标识、frontmatter、资源文件、兼容性和指纹，失败保留上一有效版本。引用的知识文件及脚本随版本管理；脚本是代码，不允许候选包执行安装钩子或扩大权限。

默认新运行使用新版，活动运行固定旧版。用户要求未执行章节立即用新版时，先暂停并校验后建立明确的新执行版本；已完成正文与确认不自动覆盖。宿主隔离未验证时禁止活动运行期间激活，不把原生热加载等同于安全替换。

## 交付与验收

使用项目已有验证器，不虚构命令或通过记录。至少验证：知识原文和相对路径真实可读；Data 映射满足章节输入；生成与直接维护均能接入；替换失败不破坏旧版；受影响单章预览可运行，依赖变化时补下游验证。

缺知识原文或 Data 未验证可以保存草案，但不能声称章节自动取数/知识齐全，也不能发布为全部可执行。阻断限定受影响章节；明确人工补料方案经确认后才可作为降级路径。

交付说明区分规范已修订、文件已生成、实际获取已完成和运行已验收。首次资源随内部整合包交付，无开发机绝对路径依赖；真实材料、凭据和无分发权限的原文不入包。不自动改旧项目、安装全局 Skill、提交推送或公共发布。
