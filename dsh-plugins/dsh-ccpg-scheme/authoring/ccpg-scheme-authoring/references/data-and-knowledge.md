# 生成章节前的数据与知识准备

本规范用于新 DSH 适配版，不改变旧平台契约。标准产品名为 CCPG CLI，实际命令为 `ccpg-cli`；Data CLI 是数据能力描述，不是另一个程序。按当前版本与公开能力核实兼容性，不将开发机的安装路径、版本或作者权限当作所有用户的条件。实际资源字段名沿用插件接入协议，不为分析报告另造执行协议。

## Data 能力不能只看命令名

1. 识别实际 Data 工具及版本，读取当前公开的帮助/结构化 schema。按章节输入从根目录发现相关命令域，不只写死 datahub、c611、item360、project-search 四个入口；不因为换版自动升级工具或开启受限构建的隐藏功能。
2. 区分“发现命令”“存在数据资产”“当前身份可访问”“字段/项目/期间/口径适配”“已验证查询结果”。仅有 help 或资产名称，不得标记为可直接取得章节数据。
3. 在授权范围内只读查询相关接口目录、schema 和最小必要样本。处理分页，未读完不能声称完整；未登录、无权限或不允许读取时标明待验证，不把未知归为不支持。不得借取数分析调用写入接口。
4. 对每个输入明确来源策略：直接取得、转换取得、人工与系统混合、只能人工、上游成果或知识。记录资产标识、能力来源、必要参数、字段映射、单位与时间口径、转换方式和验证证据。
5. 逐项比较章节所需字段与可得字段，缺少的才交人工补充。能获取一部分不代表整个材料已满足；人工与系统冲突保留双来源，由用户选择，不静默覆盖。

建议使用现有产物概念：能力快照、章节数据映射、缺口报告。报告至少体现工具版本/核验时间、章节与输入标识、能力证据、验证范围和缺口原因；不要保存完整敏感返回值、认证 Token 或查询中的个人数据作为通用规则。

章节 Skill 带上稳定数据资产/查询意图、字段要求、映射或转换引用、必要参数来源及失败降级方式；精确 CLI 命令/schema 由包内能力映射统一维护，不能只说“用 Data 查询”也不能在每章复制整套命令。运行时复核能力和当前用户权限，不把作者身份的成功当作所有用户都有权限。

## 知识必须有真实内容

1. 从原业务定义和已有 Skill 提取每章所需内部文件、飞书文档、附件及外部标准，按资源标识和版本去重。记录引用位置、用途、必需性、来源与版本；不以同名标题判定同一文件。
2. 对允许读取并允许内部包分发的文件，下载原始文件或导出正文并保存到方案资源目录。飞书文档/表格不是普通下载链接，使用对应接口取得必要正文、工作表或附件；不得将登录 HTML、预览页面、摘要或候选链接保存为“原文”。
3. 解析为章节能读取的内容，保留原文和章节/页/表定位。若保留原文件没有实际用途，可保留可追溯的原始导出及解析正文；关键表格、图片和公式不能在转换时静默丢失。扫描件需识别并核对关键内容，不以非空文件判定成功。
4. 知识索引绑定包内相对路径、来源标识/地址、版本/获取时间、内容指纹、解析覆盖及授权范围。打包时校验路径不越界、文件存在且内容有效、章节引用可解析，不能只检查 JSON 有记录。
5. 同一安装包可共享一份知识原文，章节明确指向它，不要求每章重复下载。独立章节替换时保留知识版本引用；更新所需资源一起交付或验证已安装资源满足版本，防止替换后断链。

规则编译只接受资源目录元数据中的显式 `distributable: true` 作为随包分发许可。`rightsAuthorization` 缺失、值未知或明确禁止分发时不复制原文；只存在元数据而没有有效原文时记录 `MISSING_KNOWLEDGE` 阻断。能力映射使用标准 CCPG CLI（命令 `ccpg-cli`），至少同时提供能力标识、字段列表、验证时间和明确的成功证据，不能把命令帮助、资源名称或未命名端点当作已验证取数能力。

读取权限不等于分发权限。只允许个人访问而不允许随包分发的原文不进入公共/内部通用包，明确采用每用户授权获取到项目目录的方式；实施前验证相应获取流程。无权限、来源失效、原文缺失或解析不完整时输出具体阻断及影响章节，不用模型记忆补写知识。

示例知识文件组织（不是固定 schema）：规则包内的 knowledge/<资源标识>/<版本>/ 保存正文和必要原始附件，各章节 references 中登记相对引用。实际目录须与原生 Skill 资源访问边界和插件部署方式共同验证。

## 关键验收场景

| 场景 | 必须观察到的结果 |
|---|---|
| 仅有知识 URL，没有原文 | 章节显示待获取，不能标记知识齐全 |
| 下载返回登录页或正文缺表格 | 获取/解析失败，保留缺口，不伪装成功 |
| 已取得原文但包漏文件或路径越界 | 装配校验失败，不能发布可运行版本 |
| 无原文分发权限 | 不进入安装包，说明用户级授权取得方案或阻断 |
| help 有命令但无字段/权限验证 | 只标为候选能力，不承诺自动完成输入 |
| Data 仅满足部分字段 | 取得可用部分，列出准确补料范围 |
| Data 空结果、失败或口径不符 | 不制造事实，按业务规则降级或等待 |
| 人工值和 Data 值冲突 | 保留来源和冲突，待选择后使用 |
| 替换 Skill 后知识版本缺失 | 拒绝激活，不破坏已安装版本或运行 |

这些是待实现的行为验收标准，文档检查通过不代表真实下载、查询和章节生成已通过。
