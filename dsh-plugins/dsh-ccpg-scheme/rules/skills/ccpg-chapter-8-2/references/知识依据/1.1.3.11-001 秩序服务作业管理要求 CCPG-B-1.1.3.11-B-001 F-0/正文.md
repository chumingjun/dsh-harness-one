1. 目的
规范物业服务区秩序服务的作业准则。
2. 适用范围
适用于长城物业所管项目秩序服务的管理工作。
3. 总体要求
秩序维护员在执勤中应礼貌对客，遵守《服务礼仪规范》要求。
秩序服务的所有标识均应符合公司《VI系统分类管理要求》的要求。
秩序服务人员应持对应需求证件上岗。
秩序维护员应对物业服务区的关键客户识别率达到100%。
秩序维护员应熟悉相关法律法规（国家规定的《中华人民共和国国家安全法》、《中华人民共和国反恐怖主义法》、《中华人民共和国消防法》等），并在法律法规的范围内履行职责。
秩序维护员应协助公安机关、居委会等政府部门做好社区安全防范工作。
当值秩序维护员应及时在《值班记录表》上完整记录好当天值班工作情况。
实行防火安全岗位责任制，物业项目经理为项目的消防安全责任人，秩序专业负责人为秩序部门的消防安全责任人，秩序领班为班组消防安全责任人，员工为岗位消防安全责任人。
物业项目内组织重大活动时，应及时知会辖区派出所及社区居委会。
物业项目内发生重大突发应急事件时，应及时拨打相关电话（如治安拨打"110"通知辖区派出所），报告上级领导并协助相关部门调查取证及善后处理，事后将情况填写在《值班记录表》上。
积极配合相关部门做好物业服务区法律法规政策（如消防、安全、扫黑除恶等）宣传教育工作。

4.2 安全秩序管理要求
类别
 | 
 | 要求
 | 
人防管理
 | 门岗
 | 外来人员出入物业服务区（监视区）时，应按规定对人员进出进行有效管控，做好记录，告知巡逻岗人员进行跟进。
物品进入物业服务区（监视区）时，应按规定对物品进出进行有效管控；大宗物品进入时还应进行询问并在《值班记录表》上做好记录：大件物品搬出应查询《放行条》或得到客户确认并在《值班记录表》记录后方可放行。
应熟悉危险品相关法律法规，如《危险化学品安全管理条例》规定的管理要求；并对危险品出入进行有效管控，在《值班记录表》上做好记录。
当值秩序维护人员应维护好现场门岗及所管周边秩序。
门岗、岗亭值班室应进行相关制度的上墙措施。
 | 

 | 巡逻岗
 | 熟悉物业项目的基本情况（如楼宇结构、消防设施、技防设施等）。
严格按规定路线和方式巡逻、签到，每班应至少两小时巡逻一次，特殊天气应加大对重点区域的巡查力度，并填写《巡逻签到表》；未签到或不及时签到的，在备注栏注明原因。
应对公共、装修施工、停车场（库）及重点防范等区域巡查并落实消防及安全巡查工作；及时发现并处理杂物乱堆放、共用部位/区域被占用、噪音超标、乱摆卖、车辆乱停乱放、建筑设施坏损等情况，将情况上报秩序领班/主管，并在《值班记录表》上进行记录。
准确识别外来人员，发现可疑人员应主动询问并对其行踪进行跟进。
 | 

 | 监控岗
 | 监控岗人员应坚守岗位，恪尽职守，严禁随意离开岗位区域。
应熟悉掌握服务区域内每台摄像头分布的具体位置以及各自所监控的范围，并对所有摄像头、监视器、分割画面、录像等设备进行编目编号，便于操作和实施统一管理。
应保持高度的警惕性，密切注视监视画面，随时掌握巡逻人员的动态情况。当出现报警信号或发现异常情况时，确定事发具体位后应立即向巡逻员发出指令。
发生紧急情况时，应充分发挥中央控制室的调控职能作用，及时组织协调各岗位处置突发事件，并在《值班记录表》上做好相关记录。
应熟悉并掌握相关安防系统（入侵报警、视频安防、出入口控制等系统）的操作并检查完好情况。
应检查监控室通讯系统（如五方通话等）的使用状态完好情况并按相关流程处理，如电梯困人应进行安抚工作保障通讯持续直到救援结束。
应保持室内肃静整洁，未经领导允许，禁止无关人员进入监控室。需进出的人员应在《消防（监控）中心进出人员登记表》做好记录；如需要查看录像，需要秩序专业负责人或物业项目经理同意才能查看，并填写《视频信息查阅、复制调取记录表》；每隔 30 分钟，对编号视频画面观察。
 | 
技防管理
 | 入侵报警系统
 | 每天应对入侵报警系统在不同方位测试一次，测试入侵探测和报警的实时有效性，发现系统故障应及时与维修人员沟通协调处理。
不得漏报入侵报警系统的报警信息。
 | 

 | 视频安防系统
 | 每周应对每个摄像头的监控区域测试一次，测试视频探测、视频监视、图像显示、记录与回放的实时有效性，发现系统故障应及时与维修人员沟通协调处理。
未经物业项目经理批准不得擅自调整监控范围。
发生突发事件时应将摄像头调至事件现场并重点监控。
 | 

 | 出入口控制系统
 | 每天应对出入口控制系统（防盗安全门、访客对讲系统、可视对讲系统等）进行测试，测试其进出的实时控制与管理的可靠性，发现系统故障应及时填写《值班记录表》，并上报维修人员维修处理。
 | 

 | 安全监控中心
 | 监控中心为禁区布防。
安全管理系统应保持二十四小时运行。
监控中心应设置二十四小时值班。
监控中心应配备有线和无线通信工具。
未经秩序专业负责人及物业项目经理许可，监控资料不得擅自删除。
重要监控资料应及时刻录光盘并归档保存。
监控录像保存时间应不少于一个月，特殊区域按当地要求，如深圳需三个月。
涉及重大刑事、治安案件的监控资料，未经公安机关允许不得泄露。
 | 

 | 防爆安全检查系统
 | 检查人员携带的物品是否含有爆炸物、武器和其他违禁品的电子设备系统。
重要集会场所应设置临时/永久防爆安全检查系统。
是否使用防爆安全检查系统，应充分与当地公安机关沟通并须获取支持。
 | 
异常情况及突发事件处理
 | 
 | 门岗、巡逻岗、监控岗应及时发现并处理各类事故隐患及突发事件，启动对应应急预案流程，超出职权或无法处理的情况应及时汇报领导，并在《值班记录表》上做好记录。
 | 
4.3 安全布防管理要求
类别
 | 要求
 | 

布防调研分析

 | 布防方案拟定前应对物业项目的安全防护进行现场勘察和安全因素的调研分析：
物业项目的基本情况：建筑平面图、使用功能分配图、通道、出入口、电（楼）梯、门窗、管道、墙体及周边，建设单位配置的安全防护设施。
物业项目所在地及周边的环境情况：周边地形地物、交通、社情民风及社会治安情况。
客户群体的基本情况：年龄、学历、职业，业主或承租户等情况。
当地法律法规情况：劳动时间、职业安全等等。
对防护对象（单位、区域、部位）受到威胁或承受风险的程度应进行全面评估，识别关键危险源。
确定服务区域的周界、禁区、防护区、监视区的位置。
应编制布防区域图（详见《安全布防方案》）。
 | 

防护区域

 | 禁区：物业服务区的客户自有物业区域，安全监控中心、设备房等。
防护区：物业本体共用区域、室内外停车场。 
监视区：物业本体以外，物业项目边界以内的区域，以及公共建筑的公共区域。
 | 
布防手段
 | 明确禁区、防护区、监视区的周界防护手段：实体防护（围栏、防盗门窗等）、电子防护（出入口控制系统、红外线、访客对讲、视频安防监控、停车场管理系统等）。
明确防护区、监视区公共区域的电子防护设施（视频安防系统、电子巡更系统等）。
明确关键区域秩序维护员的执勤岗位。
拟定二套以上的安防区域巡逻路线方案。
针对建设单位移交的实体、电子防护未能覆盖的盲区，合理安排人防措施。
根据布防手段结合物业项目实际情况应编制相关布防图（安防系统分布图、岗位设置图、巡逻路线图等；详见《安全布防方案》）。
 | 
布防效果
 | 周界：周界设施、系统安全可靠、经济适用。
禁区：外来人员须经业主或物业使用人授权许可方可出入。
防护区：外来人员须经门岗查问并登记备案后方可出入。具有访客对讲系统的，还须业主或物业使用人许可后方可出入。
监视区：具有实物防护周界的，外来人员须经门岗查问后方可出入。
秩序巡逻岗或视频安防监控系统的视线应覆盖物业项目的重要公共区域（停车场、大堂、物业服务区主要道路等）。
 | 
常见布防措施
 | 周界防护系统：
实体周界防护系统：物业项目红线范围设置（外墙、外墙围栏及防爬刺等）。
电子周界防护系统：物业项目红线范围、重要部位设置（电子狗、电子围栏等）。
公共区域安全防护系统：
在线/离线式电子巡查系统：巡查点设置。
视频安防监控系统：出入口、重要部位/区域、通道、电梯轿厢等区域设置。
停车场管理系统：连同收费系统设置。
监控中心
安全管理系统：各子系统联动设置。
有线/无线通信工具：无线对讲机/手机、座机、五方通话。
 | 
4.4 消防安全管理要求
类别
 | 
 | 要求
 | 
消防控制岗
 | 
 | 消防控制岗人员应严格遵守国家规定的消防控制岗岗位职责及消防控制室管理制度，及时填写《值班记录表》以及《消防控制室值班记录》（消防部门规定的火灾报警检查情况内容）。
消防控制室应进行相关制度的上墙措施。
 | 
志愿消防组织
 | 消防组织
 | 物业项目应成立志愿消防队。
志愿消防队由物业项目全体人员组成，其中物业项目经理为消防队长。
志愿消防队分为指挥组、通信组、警戒组、设备组、灭火组、疏散组及救援组，明确各组职责。
 | 

 | 组织职责
 | 消防知识普及、宣传和教育（每年应不小于二次）。
消防设施设备及其它消防工作的检查。
消防部门未到场之前，实施消防应急预案。
火灾时，配合消防部门实施灭火扑救。
 | 
消防定期巡查
 | 消防巡查内容
 | 消防控制室运行及值班情况，自动报警、灭火系统功能状态。
疏散通道、安全出口、消防通道畅通情况，应急照明及疏散标识完好情况。
防排烟系统、电气线路、室内消火栓、灭火器等设施设备完好情况。
重点部位（机房、厨房、危险品仓库等）消防安全措施落实情况。
 | 

 | 消防巡查形式及频次
 | 消防巡查应落实督查、例行巡查、重大节日/活动巡查制度。
督查：秩序专业负责人跟踪落实重点单位的消防管理工作及秩序消防巡查人员的消防检查情况。
例行巡查：秩序巡逻人员对消防巡查。
消防设施巡查：每月1次月度巡查（周、季度巡查根据物业项目实际需求增加）。
消防防火巡查：每日 1 次日巡查；每月1次月度巡查。
重大节日巡查：在天气干燥季节、法定节假日如春节前应对消防防火工作全面检查。
重大活动巡查：在活动前应对活动场所进行消防防火全面检查，活动过程应关注消防安全。
 | 

 | 消防巡查记录填写
 | 消防巡查记录应在对应资料中填写。
灭火器及消火栓的巡检记录：巡逻人员检查完毕后在《消火栓检查表》和《灭火器检查表》上填写相关内容，并签名。
消防设施巡查记录：在巡查后及时填写在《建筑消防设施巡查记录表》上，并签名；如发现消防设施故障情况，及时将有关事项填写在《建筑消防设施故障处理记录表》上，将情况上报上级和客户服务中心及相关维修部门进行处理。
消防防火巡查记录：每日的消防防火巡查应当在《消防安全社会（重点）单位每日防火巡查记录表》上填写巡查记录；巡逻人员及秩序专业负责人应当在巡查记录上签名；月度消防防火巡查应在《消防安全社会（重点）单位每月防火巡查记录表》上填写巡查记录；秩序专业负责人或物业项目经理应在巡查记录上签名，并做好归档。
年度消防设施设备及防火巡查记录可参考《建筑消防设施巡查记录表》、《消防安全社会（重点）单位每月防火巡查记录表》填写。

 | 治安类事件处置
 | 盗窃事件：发现可疑人员应立即询问并跟踪，必要时报警处理；保护现场，协助公安机关调查取证。
