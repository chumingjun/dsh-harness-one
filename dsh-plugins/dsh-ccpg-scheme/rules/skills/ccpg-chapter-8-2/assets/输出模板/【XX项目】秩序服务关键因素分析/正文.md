关键部位/岗位
 | 出入口控制（人行）
 | 人员进出频繁，访客、临时人员（施工、外卖、邮政等）混杂；大件物品搬出需管控；关键客户、政府/媒体人员需第一时间识别；道闸故障时存在出入口失控风险。
 | 【监视区】门岗管控：1.访客进入由门岗与被访者电话确认，登记并发放访客凭证，放行同时通知监控岗访客所到楼层及区域跟进。2.临时人员须提前办理临时出入凭证进入；邮政人员直接放行；政府人员出示工作证后直接放行；外卖/维修按访客流程。3.大件物品搬出凭放行凭证放行，违禁物品当场截留并留痕。4.道闸故障时即时报修，使用地桩/铁马防范，人工操作时准确填写车辆信息。5.关键客户第一时间识别并礼貌沟通；政府/媒体人员进入第一时间通知项目负责人。
 | 

 | 出入口控制（车行）
 | 车辆进出频繁；上下班高峰期拥堵；外来封闭车辆（货车等）需检查高度宽度及有无易燃品。
 | 【监视区】门岗管控：1.访客车辆电话确认后放行并登记，原则上不过夜。2.临时封闭车辆进出场检查确认放行条，搬运物品车辆出场时联系客服进行确认。3.禁止外卖、共享单车进入小区。【防护区】地下停车场：   白班巡逻岗高峰期到南2号门协助指引疏导车辆。
 | 

 | 消防控制室
 | 消控岗无证上岗风险；脱岗漏岗导致火情延误；无关人员干扰操作；上墙文件不合规；消防专话通讯中断风险；自动报警/灭火系统功能状态异常。
 | 【禁区】消防控制室属核心禁区：1.操作人员须取得消防设施操作员证等资质方可上岗。2.不得擅自脱岗漏岗（报备替岗除外），24小时值守。3.未经允许无关人员不得进入。4.上墙文件须符合国家法规要求。5.设置独立消防专用电话，确保通讯畅通。6.及时填写《值班记录表》及《消防控制室值班记录》。
 | 

 | 监控中心

 | 监控岗脱岗导致画面无人值守；摄像头遮挡/故障导致监控盲区；异常漏报；录像被私自翻录传播；资料丢失或超期。
 | 【禁区】监控中心属核心禁区：1.24小时值班，监控岗坚守岗位，不得擅自离开。2.熟悉每台摄像头分布及监控范围，编号管理；遮挡及时清理。3.密切注视监视画面；每30分钟对编号视频画面巡查；异常立即向巡逻员发出指令。4.严禁私自翻录传播；查阅/调取/复制须负责人同意，填写调取记录表。5.未经许可不得删除；重要资料及时刻录归档；录像保存不少于一个月。6.充分发挥中央控制室调控职能，及时组织协调各岗位处置突发事件。
 | 
关键活动/任务
 | 安全布防方案
 | 区域安全等级不同，需合理划分禁区/防护区/监视区并配置相应布防手段；方案与实际脱节会导致安全漏洞；建设单位移交的实体/电子防护存在盲区。
 | 布防调研分析：物业项目基本情况、周边环境、客户群体、法律法规。根据安全等级划分三大区域：【禁区】物业办公室、客服中心、游乐设施区域、中心花园、天面、设备机房、消防监控中心——最高等级，实体防护+电子防护+人防。【防护区】电梯轿厢、电梯厅、消防楼梯、地下停车场，门禁控制+巡逻签到。【监视区】园区地面、大堂、首层电梯间，巡逻监视+验证放行。  建立指挥与职责分工体系；编制布防区域图、巡逻路线图（至少两套）；每年不少于1次更新。
 | 

 | 巡逻管理
 | 人员密集区域可疑人员识别难；楼层禁区多、访客多需监视；车场车辆多需引导；夜间安全风险高；可疑物品漏报；杂物乱堆放、共用部位被占用、噪音超标、车辆乱停等秩序问题。
 | 【监视区】外围巡逻岗：1.白班：关注人员帮助、车辆引导、物品装卸监督，每1小时按路线巡逻一次。2.夜班：监视陌生人员，每40分钟巡逻一次；锁闭大堂出入口；核实临停车辆。【防护区】楼层巡逻岗：1.白班：巡查消防设施、监视来访人员动向、监督装修；非办公时间巡查门禁门窗关闭及加班人员，每2小时巡逻一次。2.夜班：每4小时巡逻一次。【防护区】地下车场巡逻岗：1.白班：巡查消防设施、高峰期疏导车辆；每4小时巡逻一次。2.夜班：重点关注固定车位，每2小时巡逻一次。【通用】主动识别可疑人员和危险物品；发现可疑物品不得擅自移动，立即上报疏散周边。及时处理杂物乱堆放、共用部位被占用、噪音超标、车辆乱停乱放、建筑设施坏损等情况。
 | 

 | 消防管理
 | 消防设施设备老化或故障；疏散通道/安全出口/消防通道被堵塞；应急照明及疏散标识缺失；防火巡查不到位导致火灾隐患未及时发现；消防器材失效或配置不足；动火作业引发火灾；志愿消防队组织架构不清；消防演练覆盖不全。
 | 【禁区】消防控制岗24小时值守，自动报警/灭火系统功能状态监控。【防护区】楼层巡逻岗落实消防巡查：1.消防设施巡查：每月1次月度巡查（灭火器、消火栓、防排烟系统、电气线路等）。2.消防防火巡查：每日1次日巡查；每月1次月度巡查（疏散通道、安全出口、消防通道畅通情况，应急照明及疏散标识完好情况）。3.重点部位（机房、仓库等）消防安全措施落实情况。【通用】1.成立志愿消防队（项目经理为队长），下设指挥/通信/警戒/设备/灭火/疏散/救援七组。2.消防知识普及每年不少于2次。3.消防巡查记录及时填写对应表单（消火栓/灭火器检查表、建筑消防设施巡查记录表等）。4.消防隐患建立台账，明确整改责任人、措施和时限；一般隐患立即整改，重大隐患上报并采取临时防范措施。5.消防器材每月全面核查，失效/损坏重新配置。
 | 

 | 应急预案与演练
 | 预案与实际场景脱节；志愿消防队组织架构不清；演练覆盖不全；应急处理不规范导致舆情。
 | 成立志愿消防队（项目经理为队长），下设指挥/通信/警戒/设备/灭火/疏散/救援等相应小组。应急响应六阶段：发现→核实→启动→处置→升级→恢复→总结。预案编制基于项目真实场景和可用资源；每年所有预案不少于1次覆盖性演练；消防演练每半年1次。及时报告记录；项目经理填写《突发事件处理表》报区域运营部门备案。
 | 

 | 关键部位钥匙管理
 | 钥匙丢失或盗用导致禁区失控；紧急情况无法开锁；私自复刻钥匙。
 | 【禁区】禁区备用钥匙保管监督：1.应有备份应急钥匙，确保紧急情况下及时开锁。2.禁止对外复刻钥匙，须经秩序专业负责人审批。
 | 

 | 关键部位安防装备管理
 | 秩序维护岗位器具损坏/缺失影响正常使用；应急工具电力不足；无装备台账导致物资管理混乱。
 | 1.秩序维护岗位所用器具应保持完好，摆放整齐，标识清楚，应急工具电力充足，不影响正常使用。2.秩序维护部门须建立《秩序维护安防物资装备台账》，列明对讲机、岗位物资的配置情况及摆放区域。3.通讯设备（对讲机及充电座）每岗1台+备用，每日检查电量、通讯畅通。4.防护装备（防刺背心、头盔、盾牌、警棍）按需配置，定期检查完好性。5.记录设备（执法记录仪）巡逻岗/门岗配置，每日检查存储空间、电量。6.应急工具（强光手电、救生绳、防毒面具）按需配置，每月检查电量、有效期。
 | 

 | 装修管理
 | 违规拆改和私搭乱建；动火作业引发火灾；材料运输损坏公区设施；高空焊接切割引发火灾爆炸。
 | 【监视区】大门岗确认是否办理装修审批。【防护区】楼层巡逻岗对装修活动进行监督。1.严防违规拆改和私搭乱建；大门岗确认是否办理装修审批。2.动火前办理手续、落实防火设施、清除易燃物；动火中专人监护；动火后巡逻岗彻底检查并监督作业方清理现场。3.注意材料运输对公区设施的破坏；施工结束监督清理。4.盛装过油类易燃液体的容器应洗刷干净；受热膨胀容器应排除爆炸危险。
 | 

 | 车辆停放管理
 | 车辆不按车位停放、在消防车道停放；车窗未关、车内贵重物品被盗；停车场照明不足、标识不清；多层地下车库需分区域管理。
 | 【防护区】地下停车场：1.车场巡逻人员应引导车辆按规定停放，维护车场良好秩序。2.不在本岗固定车位停放、不按规定停放或在消防车道停放时应及时劝阻，张贴《停车温馨提示单》。3.车停放后应及时检查车辆（是否损坏、车窗是否关闭、车内是否有贵重物品），发现异常应及时告诉车主并记录。4.地下车库应进行分区域管理，落实停车指引服务及专项车辆停放的监管工作。5.停车场标识（收费公示牌、限速/导向标识、减速带、专用车位标识等）齐全清晰。6.照明灯具配套齐全，主要通道照明亮度满足要求。
 | 
关键时刻
 | 高峰时段管理
 | 上下班高峰（7:30-9:30, 17:30-19:30）出入口通行不畅；人员秩序混乱；车辆拥堵刮擦；道闸故障加剧拥堵。
 | 【监视区】大门岗/形象岗：1.人行/车行道闸开启应满足流量需求，高峰时段保持常开或加大开启频率。2.门岗/形象岗专人引导，展示安全服务素养；外围巡逻岗主动提供帮助。【防护区】停车场：1.白班巡逻岗高峰期到车库主要出入口指引疏导；外围巡逻岗引导临停车辆规范停放。2.即时疏通出入口，摆放温馨提示，使用地桩/铁马等安全防范措施。
 | 

 | 重大活动保障
 | 活动未报备导致安全检查缺失；预案缺失；秩序形象不佳影响公司声誉；活动期间火灾隐患。
 | 1.如需地方报备应取得相关政府部门许可；重大活动应提前知会辖区派出所及社区居委会。2.提前制定安全保障方案报项目经理审批；重大活动前对活动场所进行安全检查和消防防火全面检查。3.最大限度展示安全服务素养；提前获悉活动信息（地点、规模、人数、时间）并做好安排。4.活动过程中持续关注消防安全。
 | 
关键事件
 | 个人防范及报备
 | 处置突发事件中人员受伤风险；未经报备擅自行动导致事态扩大。
 | 所有突发事件处置在确保自身安全的前提下进行；遇事件处置均需报秩序负责人。

 | 

 | 治安类事件处置
 | 盗窃（重要资料/财物被盗）；抢劫（人身安全威胁）；斗殴（现场混乱、人员受伤）；可疑物品/人员；高空坠物。
 | 1.盗窃：制定可疑人员识别与跟踪预案，明确门岗、巡逻岗、监控岗职责，定期开展防盗伏击演练；异常升级至110报警。2.抢劫：制定"确保自身安全前提下制止违法行为"预案；暴力升级至110报警。3.斗殴：制定"立即制止并隔离双方"预案；冲突升级至110报警。4.可疑物品/人员：发现可疑物品不得擅自移动，立即上报疏散周边；可疑人员应主动询问并跟踪观察。5.高空坠物：立即警戒隔离、疏散人员，排查风险源；保护现场、协助取证。
 | 

 | 消防类事件处置
 | 火灾（疏散困难、火势蔓延快）；烟雾报警（误报或真火情）；消防设施故障（消防安全失去保障）。
 | 1.火灾：制定"119报警-预案启动-初起灭火"预案，明确志愿消防队各分组职责，每半年开展综合消防演练。2.烟雾报警：制定"快速查明原因-确认火情"预案，明确消控岗24小时值守职责；真实火情立即升级至火灾处置流程。3.消防设施故障：制定"立即报修-应急替代"预案；影响安全升级至专项维修方案。
 | 

 | 自然灾害类处置
 | 台风（高空坠物、设施损坏）；暴雨（地下室灌水、大堂进水）；地震（建筑损坏、人员伤亡）。
 | 1.台风：制定"提前防范-加固-巡查"预案，明确防汛物资管理与巡查职责，台风季前开展专项演练。2.暴雨：制定"排水检查-物资准备-人员转移"预案，明确低洼区域监控职责，每半年开展防汛演练。3.地震：制定"就地避险-有序疏散-安全检查"预案，明确疏散引导与建筑评估职责。
 | 

 | 公共卫生类处置
 | 传染病疫情扩散；群体食物中毒；环境污染事件危害扩散。
 | 1.传染病：制定"配合防控-消毒监测"预案，明确公共区域消毒与健康监测职责。2.食物中毒：制定"120急救-现场保护-原因调查"预案，明确急救协助与现场保护职责。3.环境污染：制定"立即上报-疏散配合"预案，明确异常情况报告与人员疏散职责。
 | 

 | 设施设备类处置
 | 电梯困人；停电（照明中断、电梯停运）；水管爆裂；燃气泄漏；有限空间作业缺氧/中毒；停水；中央空调故障。
 | 1.电梯困人：制定"应急预案-安抚-专业救援"预案，明确监控岗安抚与维保联系职责。2.停电：制定"备用电源-照明引导-客户沟通"预案，明确重点区域巡查与解释职责。3.水管爆裂：制定"关闭阀门-排水保护-抢修"预案，明确重要设施保护与维修协调职责。4.燃气泄漏：制定"关阀通风-疏散禁火-专业处理"预案，现场控制火源。5.有限空间作业：制定"专项许可-通风检测-全程监护"预案。6.停水：制定"通知客户-应急供水-联系水务"预案。7.中央空调故障：制定"报修-通风替代-客户通知"预案。
 | 

 | 交通事故类处置
 | 停车场车辆刮擦/纠纷；道路交通事故人员伤亡；人员伤亡事故伤情恶化。
 | 1.停车场事故：制定"现场保护-协商处理"预案，明确协商协助与记录职责。2.道路交通事故：制定"报警疏导-配合处理"预案，明确交通疏导与现场保护职责。3.人员伤亡：制定"120急救-现场保护-协助救治"预案。
 | 
关键设施
 | 门禁/停车场系统
 | 系统故障导致出入口失控；车辆识别不准确；读卡器/红外探测器异常。
 | 出入口控制系统每日测试；损坏及时修复；无法修复的制定人防补位方案（地桩/铁马等）；系统运行状态记录存档备查。停车场出入口道闸出现故障或暂时失去屏障功能时必须使用安全防范措施。

 | 周界报警系统
