1. 目的
规范物业园艺服务的管理要求。
2. 适用范围
适用于长城物业项目园艺服务。
3. 总体要求
园林植物的品类、种植位置和数量应维持交付时的状态；
园林植物的色彩应当保证其原有本色；
园林植物的高低应当符合设计效果要求；
项目应具备完整的绿化档案资料，包括竣工图、植物台账、养护记录等，确保资料交接完整；
制定年度/月度园艺养护计划，明确工作内容、时间节点、质量标准；
规范作业流程，做好养护过程记录，确保作业人员安全防护措施到位；
根据天气变化灵活调整养护作业时间和方式，避免极端天气下作业，避免造成浪费；
建立恶劣天气应急预案，提前做好防风、防冻、防旱、防涝等防护措施。
4. 具体要求
4.1 乔木管理要求
项  目
 | 
 | 要     求
 | 
施肥
 | 施肥时间
 | 1.施肥时间一般选在2-3月和8-9月期间。
 | 

 | 施肥方法
 | 1.采用对角埋施，肥穴规格30cm×30cm×40cm。
 | 

 | 施肥用量
 | 1.施肥量依植物种类和生长情况而定，一般2-3kg／株。
 | 

 | 施肥种类
 | 1.施肥种类采用复合肥与花生麸等基肥相结合。
 | 
修剪
 | 修剪时间
 | 1.从3月份开始，每季修剪1次，主要修荫枝、下垂枝、干枯枝、侧缘线以及下缘线；
2.开花植物应在花芽萌动前进行，整形要与周围环境协调，以增强园林景观效果；
 | 
灌、排水
 | 日常浇灌
 | 1.南方：春季1次/月，夏季2次/月，秋季2次/月，冬季1次/月，日常浇灌要见干见湿；
2.北方：春季1次，夏季2次/月，秋季2次/月，冬季1次，日常浇灌要见干见湿。
 | 

 | 施肥后浇水
 | 1.乔木撒施颗粒肥后，需立刻浇水1次，如当天有小雨可不进行浇水，避免在中雨、大雨天气施肥。
 | 

 | 新栽植乔木浇水
 | 1.新栽植的乔木连续浇灌3次水，第一天栽植完成后应马上浇灌定根水，栽植后三天内浇灌第2遍水、栽植后十天内浇灌第3遍水，每次浇水后要注意整堰，填土堵漏；
 | 
除草、松土
 | 除草通途频次
 | 1.新栽植乔木（1-3年）及棕榈科植物应保留植穴口径80cm，每年进行1-2次除草松土、培土；
2.二年以上乔木，根已经扎深可不保留植穴并回填土（棕榈科植物除外）。
 | 
4.2 灌木管理要求
项  目
 | 
 | 要         求
 | 
施肥
 | 施肥时间
 | 1.在生长期4-10月份，根据灌木生长情况施用复合肥。
 | 

 | 施肥用量
 | 1.孤植灌木2 kg／株，密植灌木带5 kg／米，结合松土除草施于穴盘内，深度(约20-30cm)或撒施。
 | 
修剪
 | 树形修剪

 | 1.幼树修剪与整形，以整形为主，宜轻剪；严格控制直立枝，斜生枝的上位芽有冬剪时应剥掉；
2.壮年树修剪与整形，于休眠期修剪时，在秋梢以下适当部位进行短截，同时逐年选留部分根蘖，并疏掉部分老枝，以保证枝条不断更新，保持丰满株形；
3.老弱树修剪与整形，采用重短截的方法，使营养集中于少数腋芽，萌发壮枝，及时疏删细弱枝、病虫枝、枯死枝。
 | 

 | 花芽修剪
 | 1.应在休眠期进行修剪；将二年生枝基部留2-3个饱满芽或一对对生的芽进行重剪、剪后可萌发出一些茁壮的枝条；
2.一些灌木如希望当年开两次花的，可在花后将残花及其下的2-3芽剪除，刺激二次枝条的发生，适当增加肥水则可二次开花；
3.花芽(或混合芽)发生在多年生枝上的花灌木，修剪量应较小，在早春可将枝条先端枯干部分剪除，在生长季节为防止当年生枝条过旺而影响花芽分化时可进行摘心，使营养集中于多年生枝干上；
4.花芽(或混合芽)发生在开花短枝上的花灌木，一般不大进行修剪，可在花后剪除残花，夏季生长旺时，将生长进行适当摘心，抑制其生长，并将过多的直立枝，徒长枝进行疏剪；
5.一年多次抽梢，多次开花的花灌木，可于休眠期对当年生枝条进行短剪或回缩强枝，同时剪除交叉枝、病虫枝、并生枝、弱枝及内膛过密枝。寒冷地区可进行强剪，必要时进行埋土防寒。生长期可多次修剪，可于花后在新梢饱满芽处短剪(通常在花梗下方第2-3芽处)。剪口芽很快萌发抽梢，形成花蕾开花，花谢后再剪，如此重复。
 | 

 | 绿篱修剪
 | 1.绿墙、高篱和花篱采用自然式修剪较多，适当控制高度，并疏剪病虫枝、干枯枝，任枝条生长，使其枝叶相接紧密成片提高阻隔效果；
2.用于防范的绿篱和花篱，也以自然式修剪为主；开花后略加修剪使之继续开花，冬季修去枯枝、病虫枝；
3.对萌发力强的树种，盛花后进行重剪，新枝粗壮，篱体高大美观。中篱和矮篱常用于草地、花坛镶边，或组织人流的走向，这类绿篱多采用几何图案式的整形修剪；
4.绿篱种植后剪去高度的1/3-1/2，修去平侧枝，统一高度和侧萌发成枝条，形成紧枝密叶的矮墙。绿篱每年最好修剪2-4次，使新枝不断发生，更新和替换老枝；
5.整形绿篱修剪时，顶面与侧面兼顾，不能任枝条随意生长而破坏造型，应每年多次修剪；
6.地被、攀缘植物修剪应促进分枝，加速覆盖和攀缠的功能；对多年生的攀缘植物要每年1次翻蔓，清除枯枝。
 | 
灌、排水
 | 施肥后浇水
 | 1.灌木撒施颗粒肥后，需立刻浇水1次，如当天有小雨可不进行浇水，避免在中雨、大雨天气施肥。
 | 

 | 新栽植灌木浇水
 | 新栽植的灌木连续浇灌3次水，第一天栽植完马上浇灌定根水，栽后三天内浇灌第2遍水、十天内浇灌第3遍水，每次浇水后要注意整堰，填土堵漏。
 | 

 | 日常浇水
 | 1.南方春季1次/月，夏季2次/月，秋季2次/月，冬季1次/月，日常浇灌要见干见湿；
2.北方春季1次，夏季2次/月，秋季2次/月，冬季1次，日常浇灌要见干见湿；
3.对处于地势低洼处积水可采取打透气孔的方式排水(开挖若干小洞,直径50mm左右,至根部；垂直插入相同直径PVC管，周边用土填实)；
4.节约用水，采用滴灌和喷灌方式，不采用漫灌方式。每次浇水后要注意整堰，填土堵漏。
 | 
除草、松土
 | 松土时间
 | 1.绿篱每月需松土1次（最好结合复合肥），清除寄生藤1次；
2.中耕、除草宜在晴朗或雪后初晴且土壤不过分潮湿的条件下作业。
 | 
4.3  草坪管理要求
项   目
 | 
 | 要          求
 | 
施肥
 | 施肥量
 | 1.氮肥：速效氮:一般施用量不超过6g/㎡,高温时,不超过3g/㎡;缓释氮肥:按6g/㎡施用,不超过18g/㎡；
2.磷肥、钾肥：一般情况下，N：K=2：1，磷肥每年施用量为5g/㎡；
3.氮、磷、钾配比施肥：一般情况下，N：P：K=20：8.8：16,保持土壤PH值为5.1左右。
 | 

 | 施肥时间
 | 1.冷季型草坪：在深秋进行施肥；
2.暖季型草坪：在早春和仲夏施肥。
 | 

 | 施肥频率
 | 1.冷季型草坪：每年春季、秋季施2次；
2.暖季型草坪：每年春季、夏季、冬季施3次。
 | 
修剪
 | 修剪高度
 | 1.冷季型草坪：细羊茅3-7㎝；硬羊茅3-7㎝；紫羊茅4-7㎝；高羊茅5-8㎝；
2.暖季型草坪：狗牙根（普通）2-4㎝；狗牙根（杂交）1-3㎝；结缕草（马尼拉）2-5㎝；野牛草3-5㎝。
 | 

 | 修剪频率
 | 1.南方：春季1次/月，夏季2次/月，秋季2次/月，冬季1次/月；
2.北方：春季1次，夏季2次/月，秋季2次/月，冬季1次
 | 
灌、排水
 | 新栽植草坪浇水
 | 1.新栽植的草坪连续浇灌3次水，第一遍栽植完马上浇灌定根水，栽植后两、三天内浇灌第2遍水、一周内浇灌第3遍水；。
 | 

 | 施肥后浇水
 | 1.草坪撒施颗粒肥后，需立刻浇水1次，如当天有小雨可不进行浇水，避免在中雨、大雨天气施肥。
 | 

 | 日常浇水次数
 | 1.南方：春季1次/月，夏季2次/月，秋季2次/月，冬季1次/月，日常浇灌要见干见湿；
2.北方：春季1次，夏季2次/月，秋季2次/月，冬季1次，日常浇灌要见干见湿。
 | 

 | 灌水量
 | 1.一次灌透，浸湿根系土层；
2.浇水时园艺工在现场看护，用喷灌头或胶管浇水，不得出现漫灌任水自流的现象。
 | 
除草、松土
 | 除草频次
 | 1.春季0-1次/月，夏季1-2次/月，秋季1-2次/月，冬季0-1次/月。
 | 
4.4 特殊气候管理要求
项   目
 | 
 | 要         求
 | 
封冻
 | 浇封冻水
 | 1.在土壤封冻前浇一次透水。
 | 
返青
 | 返青水
 | 1.浇返青水一般在早春进行。
 | 
防寒
 | 设风障
 | 1.有主风侧或植株外围用塑料布做风障防寒，有的品种还需加盖草帘。
 | 

 | 树干防护
 | 1.树干包裹：多在入冬前进行，将新植树木或不耐寒品种的主干用草绳或麻袋片等缠绕或包裹起来，高度可在1.5-2m左右；
2.树干涂白：一般在秋季进行，用石灰水加盐或石硫合剂对树干涂白，利用白色反射阳光，减少树干对太阳辐射热的吸收。
 | 

 | 覆盖
 | 1.多用于圃地露地花卉，在霜冻前，在地上覆盖干草、草席、马粪等；另外也可覆盖塑料薄膜等材料，但需要有一定的经济条件。
 | 

 | 堆土防寒
 | 1.对于一些宿根花卉或花灌木，浇封冻水后在其根茎四周堆起30-40cm高的土堆（土堆要拍实）。
 | 

 | 树干涂白
 | 1.涂白可以反射阳光，缓和合树皮温度的剧变，对减轻日灼有明显的作用，一般在秋末冬初进行，涂白剂为：水72％+生石灰22％+石硫合剂3％+食盐5％。
 | 
抗旱
 | 遮荫
 | 1.搭建遮荫棚。
 | 

 | 叶面、树干喷水
 | 1.用水管进行喷水。
 | 

 | 整形修剪
 | 1.合理修剪，做到树形、树冠不偏斜，冠幅体量不过大，叶幕层不过高和避免V型杈的形成。
 | 
台风
 | 树体支撑加固
 | 1.在树木背风面立支撑物支撑，用铁丝、绳索扎缚加固。
 | 

 | 风后扶植
 | 1.及时扶正加固支撑风倒树木
 | 
4.5 绿植租摆管理要求
项  目
 | 
 | 要         求
 | 
摆放时间
 | 日常摆放
 | 1.日常摆放：办公区、会议室、走廊等区域可全年摆放各类绿植，增添氛围。
 | 

 | 季节调整
 | 1.季节调整：春秋季每2周调整1次摆位，夏季增加浇水频次，冬季减少浇水频次。
 | 

 | 节假日布置
 | 1.重大节日前1周完成特殊花卉及装饰布置。
 | 

 | 更换周期
 | 1.观叶植物每3个月更换1次，观花植物根据花期及时更换。
 | 
摆放地点
 | 大堂区域
 | 1.大堂区域：摆放高大绿植，营造温馨氛围。
 | 

 | 办公区域
 | 1.摆放中小型绿植，净化空气、美化环境。
 | 

 | 会议室
 | 1.摆放简洁大方的绿植，不影响视线。
 | 

 | 公共区域
 | 1.根据空间大小合理布置，避免阻碍通道。
 | 

 | 特殊要求
 | 1.避免阳光直射、空调出风口等不利位置。
 | 
摆放种类
 | 室内绿植
 | 1.绿萝、吊兰、虎尾兰、富贵竹、发财树、龟背竹等。
 | 

 | 观花植物
 | 1.蝴蝶兰、红掌、君子兰、仙客来、长寿花等。
 | 

 | 功能植物
 | 1.芦荟、吊兰、常春藤等具有空气净化功能的植物。
 | 

 | 搭配原则
 | 1.根据空间功能、光线条件、装饰风格合理搭配。
 | 

 | 安全性
 | 1.避免选择有毒、有刺、易过敏的植物品种。
 | 
养护
 | 浇水管理
 | 1.浇水管理：根据植物品种、季节、环境湿度科学浇水，避免积水。
 | 

 | 施肥管理
 | 1.每月施1次缓释肥，观花植物花期前增施磷钾肥。
 | 

 | 修剪整形
 | 1.及时修剪枯黄叶片、残花，保持美观造型。
 | 

 | 病虫害防治
 | 1.定期检查，发现病虫害及时处理。
 | 

 | 清洁除尘
 | 1.每周擦拭叶片，保持叶面清洁。
 | 

 | 记录管理
 | 1.建立养护台账，记录养护时间、内容、责任人。
 | 

4.6 档案管理要求
项  目
 | 
 | 要         求
 | 
竣工图管理
 | 收集归档
 | 1.收集归档：项目竣工验收后1个月内，收集完整的竣工图纸。
 | 

 | 档案分类
 | 1.按建筑、园林、水电、绿化等专业分类存放。
 | 

 | 电子备份
 | 1.所有竣工图需扫描成电子版，建立电子档案库。
 | 

 | 更新维护
 | 1.园区改造、绿化调整后及时更新图纸。
 | 

 | 借阅管理
 | 1.建立借阅登记制度，确保图纸安全完整。
 | 
项目平面图管理
 | 基础资料
 | 1.基础资料：收集园区总平面图、绿化布置图、管线分布图。
 | 

 | 标注信息
 | 1.在平面图上标注植物种类、规格、种植时间。
 | 

 | 动态更新
 | 1.植物增减、位置调整后及时更新平面图。
 | 

 | 多版本管理
 | 1.保留历史版本，便于追溯对比。
 | 

 | 共享使用
 | 1.共享使用：为养护、维修、改造等工作提供图纸支持。
 | 
园区植物档案建立
 | 建档内容
 | 1.建档内容：植物名称、科属、规格、数量、种植时间、位置、养护记录。
 | 

 | 信息采集
 | 1.新种植植物1周内完成建档，记录基本信息。
 | 

 | 照片记录
 | 1.每株植物建立生长照片档案，定期更新。
 | 

 | 养护记录
 | 1.记录施肥、修剪、病虫害防治等养护过程。
 | 

 | 生长监测
 | 1.定期记录植物生长状况，评估养护效果。
