4.2.1 物业服务项目标准—客户服务【输出模板】
1. 目的
规范客户服务工作中的各项标准。
2. 适用范围
适用于长城物业所管物业项目的客户服务规范。
3. 总体要求
客户服务人员宜以满足客户需求为目的提供相应服务。
《客户服务规范》是客户服务人员宜遵守的通用性要求。
在物业服务区域内，客户服务人员应执行公司《服务礼仪规范》的要求。
对于客户提出的需求，应根据实际情况分类处理：
能够即时解决的，应立即解决；
能够解决但不能即时解决的，应预约时间解决；
不能解决或有条件才能解决的，应给予合理解释并取得客户理解。
4. 具体要求
物业
 | 类别
 | 
 | 标准
 | 
业务办理
 | 入住
 | 入住通知
 | 《入住指南》、《客户装修须知》、《缴费标准告知书》应在客户办理入住手续时一并送达客户。
 | 

 | 
 | 入住接待（集中入住期间）
 | 物业服务形象宜在入住现场充分展示。
入住现场应按CCPG标识管理要求进行标识。
应有专人负责接待，并设有咨询处提供问讯服务。
入住期间的车道、停车场应有专人指引车辆停放。
 | 

 | 
 | 入住办理
 | 应为建设单位提供物业交付的一对一协助服务。
应为客户提供入住手续办理的网格管家服务。
入住手续办理流程及客户关注事项宜公示。
 | 

 | 车位租赁
 | 
 | 《车位使用方案》宜由产权方或业主大会决定。
车位使用方案、车位租赁所需资料以及手续办理流程应予以公示。
不能提供车位时，应向客户说明原因，并取得客户谅解。
 | 

 | 装修

 | 装修申报

 | 应预先告知客户装修办理的流程、装修申报所需资料、装修审核的要点。
客户装修申报发现的问题，应在当天与客户沟通和反馈。
应在2个工作日内完成全流程审批。
 | 

 | 
 | 装修管理
 | 物业服务人员应给予装修人员等同客户的服务礼遇。
客户装修需要协助时，应即时响应。
客户装修违规时，宜依照服务礼仪标准、业主管理规约、政府法规、违规处理程序处理。
 | 

 | 
 | 装修验收
 | 客户提出装修验收时，应在三天内或按预约时间组织验收工作。
装修验收合格后，应在15个工作日内办理押金退还手续。
 | 

 | 搬迁
 | 
 | 宜预先告知客户办理放行手续所需资料和流程。
放行应得到业主的确认。
大宗物品搬出应确认核验其放行凭证（线上线下放行条等均可）。
 | 

 | 收费
 | 
 | 物业服务收费标准、收费项目和依据应予以公示。
每月通过电话、企业微信、上门收费或书面形式，宜向客户提示当期费用、缴纳期限及缴费方式，避免因信息遗漏产生违约金。
如客户对费用或服务有异议，应主动了解业主未缴费原因，避免因服务瑕疵影响客户缴费意愿。
客户交费后，应向客户提供纸质或电子缴费凭证。
费用收取准确率应达到100%。
 | 
客户咨询/反馈

 | 投诉
 | 
 | 投诉受理人应就投诉事项与投诉人保持联系，直到投诉问题关闭，投诉跟踪到位率达到100%。
投诉应快速处理，投诉处理及时率应达到90%以上。
投诉处理完毕，应在三天之内回访客户，投诉回访率达到100%。
 | 

 | 咨询
 | 
 | 客户咨询宜即时回复，不能即时回复的，应预约回复。
客户咨询回复率应达到100%。
 | 

 | 建议
 | 
 | 客户建议宜做好记录，并约定回复时间。
客户建议应在三天内回复（是否采纳）并致谢，未经采纳的还应说明原因。
客户建议回复率应达100%。
 | 

 | 报修
 | 
 | 共用部位共用设施设备报修，应对客户致谢，修复后应在当天回复客户。
报修后的信息应及时准确记录。
报修处理及时率应达到90%以上。
 | 
报告与沟通

 | 管理报告
 | 
 | 年度工作计划应得到业主委员会或业主大会的批准。
政府法规要求或物业合同约定，需要业主委员会或业主大会审批的事项，应履行审批手续。
每月应向业主委员会提交《月度工作报告》，业主委员会审核后应予以公告。
每年应向业主委员会提交《年度工作报告》，业主委员会审核后应予以公告。
 | 

 | 财务报告

 | 
 | 年度预算应得到业主委员会或业主大会的批准。
政府法规要求或物业合同约定，需要业主委员会或业主大会审批的开支，应履行审批手续。
每半年，应向业主委员会提交《财务预算执行报告》，业主委员会审核后应予以公布。
每年年终，应向业主委员会提交《年度财务决算报告》，业主委员会审核后应予以公布。
 | 
客户关系维护

 | 关键客户/重要客户
 | 
 | 应对关键、重要客户定期开展拜访工作。
每月与业主委员会的沟通频次应至少一次。
春节、端午、中秋等重要节日，宜对关键、重要客户进行节日问候。
关键、重要客户拜访过程中，宜展示相关工作成果，同时收集客户对物业服务的建议与反馈，建立良好合作关系。
 | 

 | 一般客户
 | 
 | 投诉客户：对于投诉未达 4/5 星的客户，应连续 6 个月每月进行拜访。
特殊群体：对空巢老人、残障人士、重病客户等，应每年至少 1 次面对面拜访。
其他客户：应每年至少 1 次拜访，了解需求并录入系统。
 | 
社区文化活动
 | 
 | 
 | 活动前宜充分征求客户的意见。
活动过程宜营造和谐的人际关系。
活动后宜回访客户，回访率应不少于10% 。
每年组织有业主或非业主使用人参与的社区文化活动应不少于 4 次。（不同规模与级别的物业项目，应结合自身实际情况制定相应要求）
春节、端午、中秋等重要节日宜对社区进行节日氛围营造。
 | 
突发事件处理
 | 设施设备问题
 | 
 | 对突发的设施设备问题响应率应达到100%。
处理及时率应达到90%以上。
处理跟踪到位率达到100%。
处理问题时间一般不超过50分钟，如无法及时处理应立即向客户说明原因及解决问题的方案。
 | 

 | 服务问题
 | 
 | 应第一时间向客户表示真诚的歉意，得到客户的理解。
及时响应率应达到90%以上。
 | 

 | 客户突发情况
 | 
 | 及时响应率达到90%以上。
事件后应回访客户，回访率应达到100%。
 | 

 | 电梯故障

 | 有人被困
 | 接到通知后，应在5分钟内到达现场，通过对讲或现场喊话安抚被困人员，告知救援进展，保持持续沟通。
应同步通知电梯维保单位紧急到场。
应在30分钟内完成救援，确保人员安全脱困。
故障修复后应向相关客户通报处理结果。
 | 

 | 
 | 无人被困
 | 接到通知后，应在10分钟内到达现场，排查故障原因。
应同步通知维保单位到场处理。
应在当日完成修复，恢复正常运行。
若无法当日修复，应在电梯口张贴温馨提示，告知修复时限及替代方案。
 | 

 | 供水中断

 | 
 | 应在15分钟内到达现场查明原因。
营业时间段，应在30分钟内协调相关单位到场维修；非营业时间段，应在次日上午10:00前协调相关单位到场维修。
应通过公告栏、微信群等方式通知客户，提醒做好储水准备，并说明预计修复时间。
恢复供水后，应确认水压、水质正常，并向客户通报处理结果。
 | 

 | 供电中断
 | 
 | 应在15分钟内到达现场查明原因。
营业时间段，应在30分钟内协调相关单位到场维修；非营业时间段，应在次日上午10:00前协调相关单位到场维修。
应通过公告栏、微信群等方式通知客户，提醒做好用电安排，并说明预计修复时间。
恢复供电后，应确认电压稳定、设备正常运行，并向客户通报处理结果。
 | 

 | 空调故障
 | 
 | 应在30分钟内到达现场查明原因。
营业时间段，应在30分钟内协调相关单位到场维修；非营业时间段，应在次日上午10:00前协调相关单位到场维修。
应通过公告栏、微信群等方式通知客户，并说明预计修复时间。
维修期间，宜提供必要的临时降温措施（如风扇、移动空调等）。
修复后，应确认温度达标，并向客户通报处理结果。
 | 

 | 网络故障
 | 
 | 应在30分钟内到达现场排查。
属于物业内部网络问题，营业时间段，应在30分钟内协调相关单位维修；非营业时间段，应在次日上午10:00前协调相关单位维修。
属于运营商问题，应在30分钟内联系运营商报修，并持续跟进处理进展。
修复后，应确认网络畅通，并向客户通报处理结果。
 |
