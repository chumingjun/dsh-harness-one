# 旧平台经验与新插件约束

日期：2026-10-09。只读复盘，不迁移 AgentScope/Temporal 服务端实现。以下约束需进入默认运行规则、解析 Skill 和相应行为测试；文档记录不等于已经固化。

| 真实问题 | 新插件处理 | 验证方式 |
| --- | --- | --- |
| 章节被拆成大量分节/表格生成，重复读取与重试导致内容重复和口径不一致 | 同一原生会话按整章视角生成，不在插件中做第二套模型循环；必要的分批解析落盘复用 | 原生调用/材料复用记录，真实章节质量复核 |
| JSON/拼接/正则转换链改变表头和输出边界 | Markdown 主版本，结构解析保留空白单元、列位置与来源；正文/附件独立 | 编辑器往返及表格/附件契约测试 |
| 来源名称和别名未进入提示，已提供事实被误判缺失 | 章节使用当前规则中的字段名、单位、别名及精确材料引用；缺失登记确认项，不猜补 | 缺失/错误类型/来源测试 |
| 相同字节不同来源命中缓存后继承了旧证据身份 | 字节缓存复用解析内容，但每次采集单独保留来源、资源版本和范围，不把缓存当来源 | 同内容不同来源及重启测试 |
| Runtime 自动批准的记录误当成人工确认 | Agent 不可批准；编辑/材料/规则变更后撤销受影响确认 | 用户确认后编辑、变更及越权测试 |
| 原始数组顺序造成 3.x 先于 1/2 执行 | 显式章节自然顺序，依赖只决定门禁；不按导入行序或文件遍历执行 | 乱序来源及乱序包测试 |
| 权限/余额错误被 JSON 修复或无限工具重试掩盖 | 原始错误明确保留；不自动切模型/身份，不重复同一无进展操作 | CLI 失权和原生工具失败记录 |
| 索引汇编冒充知识正文，知识映射有缺口 | 原文文件、授权、hash、章节引用齐备才启用；缺失保留 blocker | 知识完整度及权利清单 |
| 改了源码但实际宿主仍是旧构建 | 构建、包版本和运行模块要一致；DSH 模块缓存须重启专用测试宿主 | 包清单/运行版本和真实页面验证 |
| 超时和重试投影把旧运行误当当前进度 | state 业务状态唯一权威，原生停止后 attempt 失效，按章节边界继续 | 中断、迟到提交及重启测试 |
