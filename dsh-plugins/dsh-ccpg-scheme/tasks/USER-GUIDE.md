# CCPG 方案插件使用说明

面向业务用户的流程：

1. 在 DSH Desktop 打开一个新的空文件夹。
2. 在会话里直接说出目标，例如：「生成物业服务方案」或「开始项目质量计划」。
3. 按提示在会话里上传文件、粘贴飞书文档/表格链接，或发送一份飞书材料清单；发送后说「材料好了」。
4. 后续在会话里说「继续」。生成后的章节、材料和附件在右侧「方案成果」面板查看、编辑、确认和导出。

不需要输入项目 ID、工具名、Skill 文件名、章节编码或内部目录。缺少必填材料时，AI 只问一个业务问题；章节被业务定义阻断时，用业务原因说明。

已有方案继续使用原来的文件夹和会话，直接说：「继续生成方案，复用已有材料和草稿。」不用重新建目录或重复上传；已提交的章节继续保留，缺少的材料按提示补充。内部错误重复出现时交给开发/运维处理，不要求业务用户或会话模型查代码。

如果旧会话已因图片过多而无法继续，在 DSH 新开会话，仍选择原来的方案文件夹，说：「继续生成方案，复用已有材料和进度。」不用重新开始方案。材料按文档处理并保存，已有结果不重复解析；扫描件或真正需要看图的内容才按需解读。

当前成果在右侧「方案成果」面板查看。左侧按业务章节编号排列；右侧显示本章输入、绑定材料、前置章节、输出项及知识/模板/案例。没有生成的章节会提示“本章尚未生成成果”。浏览器入口暂缓，不需要打开其他网址。

待确认事项按章节分别维护，不会汇总成一张全局清单。进入某一章后，点击该章顶部的「本章待确认」即可查看本章事项；每项会标明所属小节，并可定位到对应正文。确认当前章后再进入下一章，附件不继承正文待确认事项。

图片附件在目录中点开即可看原图；正文中的图片会显示在对应段落位置。下载图文章节或全文时，会打包正文和图片，图片附件则下载原件。已有附件如果只有文字说明，需要提供真实图片后再补入，文字说明无法自动还原原图。

每章保存到飞书时，插件使用你已登录的飞书账号，创建或复用本方案总文件夹，再把正文和附件一起放入本章文件夹；编号与章节目录一致。页面可以直接打开正文、本章文件夹或方案总文件夹。重复保存复用原地址，修改后更新原文档。

最终交付时，在会话里说「把完整方案和附件放到我的飞书文件夹」，或在全文页点击飞书转换。完整正文放在方案总文件夹，附件保留在各章文件夹，不重复上传。也可下载 Word 正文或包含 Markdown、图片和原件的 ZIP。

已有旧飞书成果显示“整理飞书目录”时，点击即可把已登记文档归入本章文件夹，原文档链接保持；此动作不重新生成文章。遇到权限或远端修改冲突会提示问题并停止，不另建副本。

如果方案需要 CCPG 系统数据而本机未安装或未配置 CCPG CLI，直接在会话里说“帮我初始化 CCPG CLI”。插件会检查状态，按官方手册完成可自动执行的安装、更新和配置；需要飞书集团账号授权时，会给出明确的一步操作。
