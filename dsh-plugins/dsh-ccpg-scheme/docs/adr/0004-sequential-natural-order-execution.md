# ADR-0004：按业务自然顺序串行执行章节

## 状态

Superseded by [ADR-0005](0005-native-hooks-and-user-feishu-cli.md)。首版仍串行，但已改为严格自然顺序、阻塞不自动跳章；下面 ready 集合策略是历史方案，不再执行。

## 日期

2026-10-09

## 背景

方案章节有依赖和自然先后关系。并发调度会增加状态、上下文和恢复复杂度，首版没有明确需要。

## 决策

初始化时校验缺失依赖、重复章节和循环依赖。每次从依赖已满足的 ready 集合中选择业务规则显式指定顺序最靠前的章节执行；不使用文件遍历或导入顺序。

## 结果

首版执行简单、可观察、可按章节边界恢复。未来若需要并发，必须先补充容量、冲突、取消和恢复证据，再新增决策，不在首版隐式引入。
