# ADR-0002：每个方案使用专用工作目录

## 状态

Accepted，用户已确认独立方案目录；目标 Desktop 工作区切换与初始化仍待验收。

## 日期

2026-10-09

## 背景

材料、章节成果、规则版本和恢复状态必须与其他项目隔离，且用户不应理解复杂的项目后台。

## 决策

首次使用时创建或选择一个专用方案目录，并让它成为 DSH 会话 cwd。插件只在该目录内维护 `AGENTS.md`、`.dsh/skills`、`materials`、`outputs` 和 `.ccpg-scheme`。

## 结果

不会静默把方案状态写入外层仓库。用户可以按目录复制、检查和复用成果；初始化、版本冲突和路径越界需要显式提示。
