# ADR-0001：采用 DSH 原生能力的本地插件

## 状态

Accepted，用户已确认本地原生运行方向；原生钩子接入和飞书用户身份补充见 [ADR-0005](0005-native-hooks-and-user-feishu-cli.md)。实现与目标环境验收未完成。

## 日期

2026-10-09

## 背景

首版用户是在自己的 DSH Desktop 中生成方案。旧平台包含服务端、工作流、知识和运营页面，整体迁移会带来额外运行时、部署和维护成本。

## 决策

插件只提供方案工作目录、材料入口、章节状态、成果展示/编辑、导出和飞书发布。章节生成、会话、Skill 加载、上下文读取和压缩复用 DSH 原生 Session、Agent、Skills 和文件能力。

## 结果

不引入 AgentScope Worker、Temporal、数据库或第二套聊天系统。若原生能力验证不足，先复用已有宿主接口，再以最小范围补充持久化状态；不能复制整套旧编排器。
