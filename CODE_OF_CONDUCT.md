# Code of Conduct

We want this project to be a practical, respectful place to collaborate.

## Expected Behavior

- Discuss code and product decisions with specific evidence.
- Welcome questions and different levels of experience.
- Give actionable feedback without personal attacks or harassment.
- Respect privacy and never publish another person's credentials or private data.

## Unacceptable Behavior

Harassment, discrimination, threats, deliberate disruption, doxxing, and publishing private information without permission are not tolerated in project spaces.

## Enforcement

Report conduct concerns privately through [GitHub's repository contact channel](https://github.com/chumingjun/dsh-harness-one/security/advisories/new). Maintainers may edit or remove contributions and temporarily or permanently restrict participation when necessary to protect the community.

This policy applies to repository Issues, Pull Requests, Discussions, and other spaces where someone represents the project.
